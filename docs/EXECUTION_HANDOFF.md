## 1. 用户背景与产品目标

用户 TimeCraker 是 Windows 11 / PowerShell 环境下的独立全栈开发者，主要使用 AI coding，希望 Agent 自主完成安装、开发、测试与提交，不希望每修一小部分就结束并让用户反复说“继续”。交流用简体中文，代码标识符用英文。

最初的问题：ccweb 比 Claude Code 终端难用、功能不全；手动/自动/计划/运行一切模式不清晰；Skills、Commands 与各种配置缺少分类管理；deepseekharness 的观测与控制体验没有完整体现在界面中。此前实现还出现了 UI 与已认可概念图严重不符的问题。

目标：提供好用、可靠的 Claude Code 图形客户端，让用户在 ccweb 内完成开发工作和本机运行控制，并覆盖当前基线 Claude Code 终端操作。常用功能应有直接图形交互；原生交互类能力需要可靠的原生承载。不能把“请另开终端执行”视为已经替代，也不能把内嵌终端作为所有图形体验缺口的替代品。

“完整”的验收范围必须绑定实际锁定的运行时版本、Windows 平台和账号能力，逐项列出原生操作。上游未来版本、账号不可用功能不能无条件保证；未验项目不计完成，不擅自缩减用户目标为“基本能聊天”。

独立 Harness 实验台在 V2 中明确暂缓：本轮必须做好运行观测、诊断、有效配置与追溯；批量实验、A/B 配置比较、评测任务集保留后续阶段，不用它们替代当前缺口的修复。
