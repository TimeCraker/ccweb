## IA01：URL 契约

**修复**：`normalizeBaseUrl` 去掉末尾 `/v1` 或 `/v1/messages`，其他 `/messages` 完整路径明确拒绝；`resolveMessagesUrl` 与运行时统一为 `根地址 + /v1/messages`。连接保存后展示规范化根地址，表单提示真实请求契约。

**证据**：

- 锁定运行时实际访问本机服务，输入 `/v1` 与 `/v1/messages` 两种 Base URL，最终请求均只有一次 `/v1/messages`（`runtime-path.test.ts` 2 项）。
- 探测路径与实际运行时路径由同一函数派生；单元测试覆盖根地址、`/v1`、`/v1/messages`、`/custom/messages`。
- 本机无认证网关也会真正发起请求（见 IA02），不是只测配置合并。

## IA02：认证隔离

**修复**：显式连接默认清空继承的 `ANTHROPIC_AUTH_TOKEN`/`ANTHROPIC_API_KEY`/`CLAUDE_CODE_OAUTH_TOKEN`；只有用户选择“继承本机凭证”才保留环境认证；无 Key 的连接不再静默套用其他来源。连接表单新增显式认证方式，列表显示 Key/继承/无认证。

**边界**：无认证本机网关在锁定运行时下需要非机密占位认证头才能发起请求；实现只对本机/内网地址使用 `ccweb-local-no-auth` 占位，不发送继承的真实 token。公网无认证地址不会获得占位，UI 明确提示需 Key 或继承。

**证据**：

- 服务端 12 项连接测试：空 Key、删除 Key、切换到有 Key 连接、切回无认证、native 模式、继承模式探测。
- 锁定运行时 2 项认证测试：无认证本机网关收到占位头且不包含合成 token；显式继承连接收到环境合成 token。
- 所有 token 均为虚构；`/api/connections` 仍只返回 `hasKey`，不返回原文。

## IA03：改 Key 后的结果失效

**修复**：探测签名加入草稿版本、完整 Key、认证方式与存储 Key 标记；任何表单编辑都会递增草稿版本。探测请求带序号，旧请求迟到不能覆盖新结果；改 Key/在请求中改 Key 后旧结果改为“旧测试结果已失效”，不再显示绿色“连通成功”。

**证据**（`ia.spec.ts`）：成功探测 → 改 Key → 旧结果失效；请求中改 Key → 旧响应到达仍失效；重新测试成功 → 旧响应迟到不覆盖。另有取消/双击去重既有回归。

## IA04：连接与模型搜索

**修复**：搜索同时过滤连接（名称/地址/模型）与模型；匹配连接保留“已配置连接”分组并可选中；无匹配时提示“没有匹配的模型或连接”，只匹配连接时提示“没有匹配的模型，上方连接仍可选”。

**证据**：浏览器用例创建 `AuditConnection`，搜索名称后连接可见，清空搜索恢复完整列表。

## IA05：菜单内表单键盘

**修复**：Tab/Shift+Tab 不再由菜单关闭，焦点按表单 DOM 顺序移动；只有焦点真正离开面板才关闭；Home/End/方向键在输入框内保持文本编辑语义，在菜单项上才做导航。

**证据**：自定义模型输入框填 `custom-abc`，Home/End 光标到 0/10，Tab 到“应用”，Shift+Tab 回到输入框，Esc 关闭并回焦触发按钮。

## IA06：当前会话模型选中

**修复**：选中值来自 `settings.active.model`（当前会话覆盖），不再用新会话默认判断；“使用连接默认”仅在无会话覆盖时选中；自定义值会作为“当前会话覆盖”项显示；保存默认、恢复默认、运行时拒绝均回到正确状态。

**证据**：当前会话设为 `audit-session-model` 后，该项 aria-checked=true、默认项 false；恢复默认后反过来；保存默认后按钮禁用；`audit-reject-model` 被 fixture 运行时拒绝后 chip 保持原值。截图：[model-selection.png](model-selection.png)。

## P2 / P3 / P5

- **P2 思考力度**：模型发现结果透传 `supportsEffort`/`supportedEffortLevels`；菜单与设置页只显示运行时声明的档位，未发现时只保留“默认”；fixture 声明 low/high，浏览器断言只有“默认/低/高”。
- **P3 生效范围与来源**：连接页分为“当前会话 / 新会话默认”，显示来源（ccweb 连接、本机/旧模板、原生登录）和认证方式；文案明确设置页只改新会话默认，当前会话在输入区切换。
- **P5 关键场景**：
  - 外部配置冲突：设置草稿期间外部改写技能文件，保存返回 409，界面显示“磁盘版本与当前草稿不同（草稿已保留）”，正文草稿不丢。
  - 大量文件：fixture 120 个 Edit 结果，改动面板显示 120 个文件，摘要可读、列表可滚动到最后一项。
  - 断线附件：强制关闭 WebSocket，图片与文字草稿保留，自动重连后仍可发送并完成。
